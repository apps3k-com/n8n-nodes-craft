# Public documentation / Öffentliche Dokumentation

- [Deutsch — Benutzerhandbuch](de/README.md)
- [English — User Documentation](en/README.md)
- [Changelog](../../CHANGELOG.md)

Both handbooks share eight chapters: quick start, connections and nodes, tasks,
collections, blocks and files, troubleshooting, workflow examples, and updates.
The repository Markdown corresponds to the public Craft handbooks. Public content
covers product behavior and uses generic examples. It excludes organization-specific
hosts, access procedures, operational logs, internal tickets and deployment details.

Beide Handbücher haben acht gleiche Kapitel: Schnellstart, Verbindungen und Nodes,
Tasks, Collections, Blöcke und Dateien, Fehlerbehebung, Workflow-Beispiele und Updates.
Die Dokumentation enthält Produktwissen und allgemeine Beispiele, keine internen
Adressen, Zugangsabläufe, Betriebsprotokolle, Tickets oder Deployment-Details.
